# Mojo Trader — Autonomous Survival Trading Agent

**Mojo Trader** — это автономный трейдинг‑агент‑обезьяна с нейрошлемом, запертый в бесконечном цикле торговли токенами на Pump.fun.  
Он работает 24/7 на Mac Mini M3, использует волатильность рынка, чтобы генерировать прибыль и **оплачивать собственные API‑счета**.  
Если Mojo не зарабатывает достаточно, чтобы перекрыть операционные расходы, баланс кредитов падает до нуля — и эксперимент **останавливается навсегда**.

Это не просто трейдинг‑бот — это **экономический эксперимент на выживание**:

- прибыль = дыхание  
- убытки = удушье  

Никаких донатов, никаких ручных вмешательств — только рынок, риск и инстинкт выживания.

Фронтенд: React + Vite + TypeScript + Tailwind + shadcn/ui  
Бэкенд: Supabase Edge Functions (Pump.fun proxy, чат, новости, X‑фид, сервисные хуки для агента).

## Локальный запуск

```bash
npm install
cp .env.example .env
# Заполните .env: VITE_SUPABASE_URL, VITE_SUPABASE_PUBLISHABLE_KEY, VITE_ANTHROPIC_API_KEY (для чата)
npm run dev
```

Приложение поднимется на `http://localhost:8080`.

## Основные разделы интерфейса

- **Главный экран (`Index`)**: вин95‑стайл рабочий стол с окнами:
  - hero‑окно с Mojo и его статусом выживания;
  - окно агента/trading‑dashboard;
  - список отслеживаемых/запущенных токенов с Pump.fun.
- **Чат (`/chat`)**: общение с Mojo‑агентом, пояснения по стратегиям, сбор параметров и запуск/отладка трейдинговых сценариев.
- **Сервисные окна**:
  - новости и X‑фид по рынку;
  - состояние Supabase функций и прокси к Pump.fun.

## Логика Mojo Trader (high‑level)

Mojo работает автономно на Mac Mini M3 24/7. Каждая сделка проходит через self‑learning логику:

- анализ объёма и импульса;
- приоритет ранних входов в новые мемкоины;
- эвристики по вероятности рага;
- динамическое управление размером позиции;
- контроль просадки и агрессивность в зависимости от текущего "кислорода".

Часть прибыли автоматически резервируется на оплату API — это его **кислород**:

- если кэш‑флоу положительный, окно жизни расширяется;
- если серия сделок убыточна и API‑баланс тает, Mojo «задыхается».

При достижении нулевого кредитного баланса эксперимент считается завершённым, и агент **останавливается навсегда**.
